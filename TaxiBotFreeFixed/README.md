Готовый бесплатный проект TaxiBotFree для Render (исправленный requirements.txt).

1. Замените TELEGRAM_TOKEN в bot.py или через переменную окружения на ваш токен от BotFather.
2. В Start Command Render укажите:
   pip install --upgrade pip wheel setuptools
   python bot.py
3. Залейте проект на Render Free (Web Service → Python).
4. Добавьте бота в группу и дайте права на отправку сообщений.
5. Бот присылает тарифы Яндекс.Такси текстом по присланной локации.
